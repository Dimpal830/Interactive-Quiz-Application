# Interactive Quiz Application

A browser-based quiz with 10 programming questions, instant feedback after each answer, a progress bar and a final score.

## Features
- One question at a time with a progress bar
- Instant correct / wrong feedback, with the right answer shown
- Live score and result message
- Restart button
- Works on mobile and supports dark mode

## Technologies
HTML, CSS, JavaScript

## How to run
Open `index.html` in any browser.

## Customise
Edit the `questions` list at the top of `script.js` to add your own questions.
